功能 / FEATURES

像玻璃一样轻，
像网格一样稳。

我们打磨的不是按钮，而是「手感」——让每一次拖动、缩放与同步都安静而自然。

无限画布

画布没有边界。缩到能俯瞰全局，放到能看见一个像素。每一层内容都悬浮在独立的玻璃片上。

实时协作

光标可见，评论跟随内容移动。十个人同时画，也不会互相踩脚。延迟低到你几乎感觉不到距离。

时间回溯

每一个操作都被记入时间轴。随时回到三小时前、三天前，甚至上一次迭代的任意一刻。

一键分享

生成一条透明链接，对方无需注册即可查看或留言。权限精确到「只看 / 可评 / 可画」。
