# 站点制作统一规范（所有风格都必须遵守）

每个站点是**完全自包含**的静态网页，放在自己的子目录中，由三个文件组成：
- `index.html` — 页面结构
- `style.css` — 全部样式
- `script.js` — 全部交互（无外部依赖，纯原生 JS）

## 硬性要求
1. **无外部图片依赖**：所有视觉元素（背景、图案、图标、插画）必须用 CSS 渐变、内联 SVG、CSS 形状实现。禁止引用外部图片 URL。
2. **字体**：可以引入 Google Fonts（`<link>`），但必须给**中文字符**配置系统字体回退栈（如 `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`）。中文内容为主，英文为辅，保证离线也能正常显示。
3. **响应式**：至少适配 375px 手机、768px 平板、1280px 桌面。用 `@media` 断点。
4. **语义化 HTML**：`header / nav / main / section / footer` 等标签正确使用。
5. **可访问性**：对比度足够；交互元素有 `:hover` / `:focus` 状态；图片/图标用 `aria-hidden` 或 `alt`。
6. **JS 无报错**：`script.js` 必须能运行且控制台无错误。交互要「有意义」——贴合该风格主题（如像素站的复古音效、杂志站的阅读进度条），不要为加而加。
7. **中文文案**：全部内容用中文（可夹带少量贴合风格的外文点缀，如英文标语/法文名），文案要贴合该站的主题，不能是占位符 `lorem`。
8. **完整页面**：必须包含多个区块，典型结构为：导航栏 → 首屏 Hero → 关于/介绍 → 特色/服务/作品集（列表或网格）→ 数据/引用/团队 → 底部 CTA → 页脚。具体区块依据风格和主题灵活调整，但至少 4 个内容区块 + 页脚。
9. **原创性（最重要）**：严格遵守简报中指定的配色、字体、布局结构、视觉特效与交互方式。不允许和「换个颜色」的做法有任何相似——相邻站点在视觉上必须有肉眼可辨的巨大差异。
10. 禁止使用 `<marquee>`。禁止复制其他站点的实现思路。

## 文件编码
- 全部 UTF-8，`<meta charset="UTF-8">`。
- `<html lang="zh-CN">`。
- 每个文件的 `<title>` 写该站点名称。

## 页面标题规则
- 每站 `<title>`：`风格名 · 主题名`，例如 `瑞士极简 · 线性设计工作室`。

## 目录
```
sites/<编号>-<风格名>/
  index.html
  style.css
  script.js
```
